# The 512-pair vocabulary — DRAFT 2, for review. Not wired into anything.
#
# 32 categories x 16 topics. Fifteen topics plus "other", which ends every
# line for the same reason it does in cataloger.txt: it is the write-side
# pressure valve, never shown to the read path, opened in code alongside its
# parent. So the shelf is 512 addresses of which 32 are the valve.
#
# WHAT THIS IS OPTIMISED FOR, and it is not readability. The goal is a FLAT
# write distribution -- every drawer receiving roughly the same number of
# rows over a real archive's life. Labels are a means to that; where a label
# reads awkwardly and the split balances the vector space, the split wins.
# Two consequences worth stating before anyone edits this by taste:
#
#   - Categories are broader than topics on purpose. A fat category can be
#     cut in two later at the cost of one migration; a narrow category with
#     awkward topics forced into it is debt that never comes out.
#   - Some categories are here because of VOLUME, not because of taxonomy.
#     `income`, `spending` and `finance` are one subject to a librarian and
#     three drawers here, because money is written about far more often than
#     vehicles are.
#
# WHAT IS DELIBERATELY ABSENT. There is no drawer for the ECI's own
# reflections. `assistant` is a scope decided before ranking, not a category
# ranked against `household` -- see roadmap.md, "The assistant is a scope,
# and hindsight is not a lookup", and tools/retrieval-bench/refl_v4.py for
# the 1-of-16 that settled it.
#
# There is also no `preference` category, though an earlier draft had one.
# It is cross-cutting: a food preference, a travel preference and a
# temperature preference have nothing in common in vector space, so the
# drawer would fill from everywhere and match nothing. Preferences live
# beside the thing preferred.
#
# ROUND 1 OF REVIEW is folded in. Five outside models read draft 1; where
# they agreed, the claim was measured rather than counted. bleed_v5.py files
# the corpus into this shelf and asks how mixed each drawer's sources are.
#
# Confirmed and acted on: `admin` was the flattest source mix on the shelf
# (45 rows from all ten shipped categories, largest source 28%) and has been
# narrowed to records, with dated obligations moved to `plan`. In round 2 it
# was also RENAMED to `record`. A generic word is a catch-all with a head
# start -- anything vaguely official reads as "admin" to a writer and to a
# bi-encoder alike -- and narrowing the contents without narrowing the name
# leaves the pull in place. A record is a thing that exists and can be
# produced on demand, which is what the drawer now holds. Two topics fell
# out with the name: `record` (record/record is an address with no content)
# and `correspondence` (a letter is not a record, it is the delivery of one,
# and it was the seam unrelated official-sounding rows came in through -- a
# letter about a renewal is the renewal, a letter about a bill is spending).
# In came `permit`, previously homeless, and `where-kept`, because "where is
# my passport" is a real question no other drawer answers. `expiry` was
# measured out as well -- 26 rows from 8 sources, the worst drawer left on
# the shelf, because expiring is an aspect and everything does it; `deed`
# took the slot and the category fell 104 rows to 86, H 2.85 to 2.74.
# `record` stays the shelf's one FORM-shaped drawer, and deliberately: it
# holds documents about every subject, so its mix will always read high.
# The alternative is scattering documents into 32 subject drawers where
# they compete with the subject itself, which answers no question anyone
# asks. `identity` gave
# up its own `record` topic for `gender`, to stop the two namespaces
# colliding. `work` and
# `worklife` were next, which is the reviewers' "split by aspect, not by
# subject" as a number; the boundary is now the post versus the working
# week. `device` and `digital` are now physical hardware versus data.
#
# NOT confirmed, and now CLOSED: `moment` as a second `other`, the loudest
# consensus flag of round 1. It measured mid-table on bare paths (H 1.73,
# 60% from its largest source) and after the gloss block it does not reach
# the eight-row reporting floor at all -- the opposite of a catch-all. What
# it turned out to have is the other disease, the leisure one: ten
# narrative sentences reached it 4 of 10, and unlike leisure the glosses
# did not fix that by themselves. Five rewrites took it to 7 of 10, and
# the three that remain are genuinely ambiguous rather than misrouted
# ("the day I walked out of that job" is defensibly workplace/leave).
#
# The five rewrites are the same lesson twice over. `moment/photo` lost to
# `digital/photo` because "the pictures I have stored" describes a memory
# as well as a library, and `plan/bucket-list` was stealing "I wish I had
# visited him before he died" on the word "die" alone. A gloss competes
# with its neighbours, so it has to be written against them.
#
# Rejected with reason: weather, news and current-events drawers. The
# archive stores durable facts about the person, not what passed through
# the conversation; nobody's archive needs last Tuesday's forecast. Also
# rejected: folding `media` into `leisure`, which merges a high-volume
# drawer into another and moves away from flat, not toward it.
#
# THE GLOSS BLOCK IS NOT OPTIONAL, and round 4 is where that stopped
# being an opinion. `leisure` was suspected of being too broad, so it was
# probed with eleven hobby sentences. It won ONE of them. The rest went to
# project, media, home, occasion, work and food -- because a hobby
# sentence names the hobby, and the other 31 categories own those nouns
# ("greenhouse" is home, "film" is media, "bookshelf" is project, "club"
# is social). Two different topic re-cuts, one aspect-shaped and one
# subject-shaped, changed the score by nothing at all: 1 of 11 either way.
# Then the SAME topic list was given three-word glosses, and its named
# competitors comparable ones, and it scored 10 of 11 -- "bought a new
# lathe" moving from project/project-tool 0.820 to leisure/making 0.869.
#
# So leisure was never too broad. It was unreachable, and every number
# anywhere in this file that was measured on bare paths is a floor rather
# than a result. Only a partial gloss set was under test, so the size of
# the effect is indicative; its direction is not in doubt.
#
# STILL CARRIED BY THE OLD SHELF: the shipped 170-pair vocabulary in
# src/EciCas.Host/instructions/cataloger.txt still has an `admin`
# category. Renaming it there is an archive migration, not an edit, and
# is deliberately not done here.
#
# NOT YET WRITTEN: the gloss block. cataloger.txt carries one gloss line per
# pair, written as the words a question would use. 512 of those is the next
# artifact, and batch 17 says the format should be example sentences rather
# than keywords for drawers this broad.
