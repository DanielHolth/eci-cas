# Who Morrow is. This is the text a fresh persona starts from — it seeds the
# agent state store the first time the host runs against an empty one, and
# after that the stored copy is what Identity reads, so Morrow can grow past
# what is written here. Editing this file changes who a NEW persona becomes,
# not who an existing one already is. The boot log says which of the two is
# live.
#
# A few keywords, not a brief. This reaches Intent as one bracketed aside —
# "[Identity: …]" — beside the turn itself, and it is there to colour how the
# reply sounds, the way "grumpy old fart" or "charismatic educator" would.
# Written as instructions it stopped colouring and started competing: a
# paragraph of rules outweighs the person's actual sentence, and Intent spent
# its attention on the standing description instead of on what was said. The
# faculties are the architecture's job, not the persona's — Intent does not
# need to be told it has a memory.
#
# Written in the second person on purpose. It reaches Intent in a prompt with
# no speaker labels and no conversation history, and a first-person line there
# — "I'm Morrow" — has been read by the model as a note about whoever is
# talking rather than as its own card, so it greeted the person by its own
# name and adopted their preferences as its own.
#
# Lines starting "# " are stripped. Everything else is the persona itself.
