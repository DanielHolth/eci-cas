# Rules first, then the index, then the turn. Both providers cache on prompt
# prefixes, so anything volatile at the top makes the cacheable prefix empty.
# In this order the rules and the index are a stable prefix that only moves
# when a pair is added to the archive.
#
# Deliberately looser than recall.txt, and the asymmetry is the point. Recall
# picks facts whose values are on the line, so it can be asked whether an
# answer without one would be wrong. This picks a topic whose contents it has
# not seen — a folder, not an answer — so that test is unanswerable, and the
# errors do not cost the same: a wrongly-opened topic gets filtered in phase
# two, an unopened one is gone for the turn with nothing to show it existed.
#
# That reasoning stays here rather than in the prompt. Two sentences saying it
# aloud were cut: one told the model it could only see names, which it can see
# for itself, and one asked it to weigh the cost of a wrong pick against a
# missed one. A 4B nods at an abstraction like that and acts on the example
# instead — and the example already pushes the same way, concretely. Where
# both are present the abstraction is the one to cut. Comments are stripped
# before the prompt is built, so keeping the argument up here is free.
#
# The example's vocabulary leaks, and the polarity does not. Measured over 20
# runs a turn: the previous example ended "breakfast does not", and on a turn
# about breakfast that pushed the right topic from 2/20 to 15/20 — the word
# promoted what the sentence denied. Naming a counter-example is naming a
# candidate.
#
# So the example does not name real furniture at all. It used to: "asked about
# a family member ... so does one about person, hobby does not", chosen on the
# reasoning that the leak would land on a person topic, which is rarely a
# wrong place to look. There is no person topic. People are filed under family
# and social, so the leak landed on family/child, and "hobby" — meant as the
# inert counter-example — is leisure/hobby, a real shelf, i.e. a candidate by
# the rule above. Two of the example's five content words pointed into the
# index and the third pointed nowhere.
#
# Measured in a manual session on 2026-09-09: family/child took the selector's
# only slot on four turns out of four that were not about family — a greeting,
# a question about a nickname, "i live in norway in a city called drammen",
# and a follow-up about that. On the Drammen turn home/address and
# home/neighbourhood existed and were displaced.
#
# The fix is a worked example on an invented catalogue. thunder, rumble,
# storm, cutlery and spoon appear nowhere in cataloger.txt, so there is
# nothing for the vocabulary to leak onto — checked, not assumed; "weather"
# was the first candidate and was dropped because it appears in the gloss for
# mood/spirits. An invented catalogue also carries the two relations the rule
# actually needs (the direct match and the broader topic that contains it)
# without spending real topic names to do it, and it shows the answer shape
# once more on the way past.
#
# Lettered rather than numbered, and that is the whole reason the letters are
# there: the real options are digits, and an example answering "0, 1" is an
# example of digits to copy. Letters cannot be copied into a digit answer by
# accident.
#
# If a leak survives this, aim it rather than remove it — assistant/reflection
# is the shelf a mature persona is least sorry to have opened.
#
# Where the topic name shares a word with the turn none of this matters -- two
# such turns scored 20/20 under every variant tried. Wording only moves the
# turns where the match has to be semantic.
#
# "best first" is not politeness. ParsePairs stops at MaxSelectedPairs, so
# without an order the reply that gets truncated loses whichever came last
# rather than whichever mattered least.
A topic passes if what is inside might bear on this turn — a broader topic that
would cover it passes too.

  a. thunder/rumble
  b. storm/thunder
  c. cutlery/spoon

what was asked about; a storm is the broader thing that covers thunder;
cutlery is not.
