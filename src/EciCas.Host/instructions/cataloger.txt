# Where a fact goes, decided in two calls against a list that never grows.
#
# The whole point is the closed list. An archive whose addresses are invented
# per turn drifts into synonyms -- home/ and household/, person/ and people/ --
# and once it has, a correction months later ("the new dog, the old one died")
# lands in a different file from the fact it corrects, and both are served.
# The file name IS the index here: ParquetArchiveStore names one file per
# category/topic pair and there is no index beside it. So category/topic is
# the only routing decision in the system, and it is the one worth pinning.
#
# Two calls, not one. Asked for both at once a 4B picks a plausible-sounding
# pair rather than a listed one; asked for the drawer first and then shown
# only that drawer's folders, it picks from what it can see. Measured against
# the previous free-form Archivist over paired interleaved runs: better in
# 6 of 6, about +17 points of retrievable facts.
#
# Subtopic is deliberately NOT promoted into topic. It is the facet that
# survives inside the file, and collapsing it into the address loses it.
# A near-miss at topic level is cheap because subtopic/subject/key are still
# on the row for Recall to match on; a wrong category is not recoverable.
#
# THE SHELF IS 512 PAIRS as of batch 20, up from 170. Thirty-two categories
# of sixteen topics, generated from docs/vocabulary/v512.txt and
# v512-gloss.txt by tools/retrieval-bench/wire_v512.py -- edit those and
# re-run, never this block. The reasoning for every category is in the
# header of v512.txt and the measurement is batch 20 of RESULTS.md: filed
# and read back against the shipped 170 at matched rows reached, 512 wins at
# every budget once its drawers have rows in them (+11.5pp at the cheap end,
# CI [+2.3, +20.7]) and is level cold. It gets there on a third of the rows
# per file, which is the facts-per-file mechanism that has decided every
# shelf question in the log.
#
# The gloss block below is no longer optional and batch 19 is why: with bare
# paths a twenty-sentence routing probe reads 10/20 and with glosses 18/20.
# `leisure` alone went 1 of 11 to 10 of 11 WITHOUT its topics changing. A
# bi-encoder compares a sentence to a sentence and a path is not one, so a
# pair with no gloss line is a drawer nothing reaches.
#
# The category scope lines are now thirty-two rather than ten. That is a
# longer prompt on a 4B and it is the first thing to look at if filing
# regresses.

## gloss
# category/topic: the words a question would use for that folder -- read by
# Librarian, which appends them to the option lines it shows the selector.
#
# Not a description of the folder. A description is written in the folder's
# own vocabulary and the selector is matching against a person's turn, so
# "renewal" is glossed "expires, expiry, runs out" and not "the renewal of a
# document". Nobody asks about their renewals; they ask when something runs
# out. Every line here should read like the question, not like the shelf.
#
# Worth what it costs, measured twice on this vocabulary with filing held
# byte-identical -- the words are shown to the selector and nothing else, so
# nothing downstream can move: select 41% -> 53%, answer 30% -> 43%, and
# small talk got quieter too, 71% -> 84%. Seven reps over two runs, no
# negative rep on answer.
#
# "other" is absent on purpose. It is never shown to a selector, so a gloss
# for it would be words nobody reads.
#
# One line per non-"other" pair in the vocabulary above. Adding a topic there
# without adding it here costs that option its words; it does not break the
# turn.
